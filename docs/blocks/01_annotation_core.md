# Блок 1. Базовый цикл полуавтоматической разметки

Задачи ТЗ: интеграция SAM2; интерфейс для массовой работы с объектами;
групповое удаление, переопределение классов и редактирование.

## Что реализовано

- Окно разметки — наследник окна LabelMe 5.2.1; исходники LabelMe не изменяются.
- Промты SAM2: положительные/отрицательные точки, прямоугольник, круговой
  промт одного объекта. Промт не открывает диалог выбора класса.
- Запрос к модели выполняется в фоновом потоке; результат — кандидаты в панели
  `SAM2 Candidates`, которые пользователь принимает или отклоняет.
  Временные объекты (промты, кандидаты) не попадают в сохраняемую разметку.
- Массовые операции (меню `Batch`): выбор всех объектов, по классу и внутри ROI
  (по центроиду), групповое удаление с подтверждением, назначение класса.
- История изменений текущего изображения (undo/redo, до 100 снимков).
- Атомарное сохранение LabelMe JSON.
- Совместимость LabelMe с NumPy 2.x: собственный расчёт расстояния до отрезка
  вместо `np.cross` (иначе GUI падал при наведении на контур).

## Модули

`app/gui/labelme_window.py`, `app/gui/worker_task.py`, `app/core/history.py`,
`app/core/selection.py`, `app/core/geometry.py`, `app/compat.py`,
`app/worker_api/`, `worker/main.py`.

## Ограничения

Отмена запроса отбрасывает результат, но не прерывает вычисление в worker.
История сбрасывается при смене изображения.
