# Блок 5. Проверка, импорт и экспорт разметки

Задача ТЗ: подготовка размеченных датасетов для задач машинного зрения.

## Что реализовано

- Проверка перед экспортом: классы, ID, границы кадра, самопересечения,
  вырожденные фигуры, пустые маски, дубли. Ошибки блокируют экспорт,
  геометрия молча не исправляется.
- Экспорт изображения: LabelMe JSON, COCO (RLE, сохраняет отверстия),
  YOLO-сегментация, бинарные и индексированные PNG-маски, CSV свойств.
- Экспорт всего проекта: COCO/YOLO/маски, разбиение train/val/test по seed
  на уровне групп (кадры одного стека не попадают в разные выборки),
  `manifest.json` и `report.json` для воспроизводимости.
- Импорт COCO (полигоны, RLE, bbox) и YOLO (bbox, полигоны) в текущее изображение
  с отчётом о пропущенных объектах.
- Все экспорты публикуются атомарно в новую папку; исходники не изменяются.

## Модули

`app/core/export.py`, `app/core/dataset_export.py`, `app/core/importers.py`.

## Ограничения

Разбиение не стратифицируется по классам. YOLO не принимает маски с отверстиями.
Импорт — для текущего изображения; keypoints/OBB не поддерживаются.
