# Блок 4. Научные изображения

Задача ТЗ: поддержка данных биомедицинских и физических экспериментов
(микроскопия, многоканальные снимки, последовательности кадров).

## Что реализовано

- Чтение 8/16/32-битных, float и многоканальных изображений
  (Pillow; многоканальные 16-бит и оси TCYX — через `tifffile`).
- Детерминированное 8-битное отображение: auto (перцентили) или manual окно
  интенсивностей, гамма, выбор 1–3 каналов. Исходные данные не изменяются.
- Модель получает то же представление, что видит пользователь: настройки
  передаются в worker и входят в ключ кеша embeddings.
- Настройки сохраняются в проекте для каждого изображения и записываются
  в манифест экспорта.
- Многостраничные стеки (T/Z) без потерь разбиваются на кадры `<имя>_frames/`.

## Модули

`worker/imaging.py`; меню `Image display` в `app/gui/labelme_window.py`.

## Ограничения

Без проекта настройки отображения действуют до закрытия приложения.
Модель работает с 8-битным представлением, а не с исходным динамическим диапазоном.
