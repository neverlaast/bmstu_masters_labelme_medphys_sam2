# Блок 2. Поиск множества объектов и специализированные промты

Задача ТЗ: специализированные промты, в том числе круговые области интереса
для поиска частиц, клеток и других округлых объектов.

## Что реализовано

- ROI поиска: круг, прямоугольник, полигон или всё изображение.
- ROI преобразуется в сетку точечных промтов SAM2 — это собственное
  преобразование, энкодер SAM2 не изменяется.
- Фильтры кандидатов: площадь, эквивалентный диаметр, отношение сторон,
  круглость, выпуклость, доля маски в ROI, оценка модели, касание границы.
- Подавление дублей по IoU бинарных масок (mask-NMS); предупреждение
  о перекрытии с уже существующей разметкой.
- Уточнение маски: модели передаются logits выбранной маски и новые точки;
  принятый объект заменяется с сохранением ID.
- LRU-кеш embeddings (2 изображения / 128 МиБ) и состояний уточнения (128 масок).
- Исходная маска хранится в метаданных объекта как RLE.

## Модули

`worker/postprocess/`, `worker/cache/embedding_cache.py`,
`worker/predictors/sam2_predictor.py`, `app/gui/generation_dialog.py`.

## Проверка

Реальная SAM2.1 tiny/small на MPS на синтетическом изображении: найдены
отдельные объекты, повторно использован кеш, применено уточнение маской.

## Ограничения

Единицы фильтров — пиксели; калибровки в микрометрах нет. До 128 кандидатов
за запрос. Растрового редактора масок нет.
