# Блок 3. Проекты, реестр классов и надёжная работа с файлами

Задачи ТЗ: переопределение классов и редактирование разметки в масштабе
набора данных; удобство подготовки датасетов.

## Что реализовано

- Формат проекта `*.medphys.json`: версия схемы, относительные пути и SHA-256
  изображений, аннотации, классы, настройки, сведения о моделях, журнал.
- Строгая проверка при открытии; поиск перемещённых изображений по SHA-256.
- Атомарная запись, резервные версии, защита от перезаписи файла,
  изменённого извне; автосохранение по интервалу.
- Реестр классов: стабильные ID, цвет, описание, атрибуты, допустимая
  геометрия, горячие клавиши, активность; безопасные переименование,
  перенос объектов, деактивация и удаление; отдельный undo/redo структуры.
- Фоновые файловые операции с прогрессом и отменой: открытие проекта
  с проверкой контрольных сумм, экспорт датасета, разбиение стеков,
  автосохранение. Ручное сохранение дожидается текущего автосохранения.

## Модули

`project_format/`, `app/gui/project_window.py`,
`app/gui/project_classes_dialog.py`, `app/gui/io_jobs.py`.

## Ограничения

Проект хранит ссылки на изображения, а не сами файлы. Undo не
восстанавливается после перезапуска. Отдельного диалога восстановления
резервной версии нет.
